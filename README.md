# Mohammed Ashraf — Portfolio

A responsive, dark-themed, backend-focused developer portfolio built with semantic HTML, CSS, and lightweight vanilla JavaScript. The current Dubai resume is included locally and linked from the navigation and hero section.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project files

- `index.html` — page content, project cards, SEO metadata, and links
- `style.css` — responsive dark-theme styling and CSS illustrations
- `script.js` — accessible mobile navigation and dynamic copyright year
- `assets/Mohammed_Ashraf_Resume.pdf` — resume PDF linked from the portfolio
